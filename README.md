# Хозяйство мамы · 3–8 сентября 2026

Мама уехала на Алтай, хозяйство на мне: собаки, щенки, козы, куры. Распорядок
дня, разовые дела и вопросы, которые надо ей задать, — на одной странице.
Один `index.html`, без сборщиков: статика, открывается прямо в браузере.

Запуск: `python -m http.server 8742` из корня, открыть `http://localhost:8742`.

Сделано на основе [my-schedule](https://github.com/rediiskka/my-schedule) и
[raspisanie-3bi1](https://github.com/rediiskka/raspisanie-3bi1): оттуда палитра
и обе темы, раскладка, виды, метки, погода и вся механика показа. Расписание
вуза вырезано — здесь его нет ни строчкой.

## Как это устроено

- **Дела** — в `my-data.json` и `index.json` рядом в репозитории, зашифрованные
  паролем. Дело устроено как занятие: время, категория, место, заметка, метки.
  Каждое лежит своим фрагментом: новое дописывается одной строкой, прежние не
  переписываются. Индекс читается первым, поэтому расшифровывается только
  показанный отрезок, а не весь файл.
- **Распорядок повторяется правилом, а не копиями.** Одно дело — один фрагмент
  с `repeat`, и на экране оно раскрывается во все шесть дней. Сдвинуть дойку на
  час — одна правка, а не шесть.
- **Дней хозяйства ровно шесть.** Каркас 3–8 сентября строится в коде
  (`PERIOD` в `index.html`), отдельного файла с пустыми днями нет: его пришлось
  бы держать в согласии с датами руками.
- **Сайт только читает.** Pages отдаёт статику, писать в репозиторий из браузера
  нельзя, поэтому формы правки в интерфейсе нет. Файлы правит `tools/vault.py`
  с машины, результат уезжает коммитом.
- **Кроме галочек.** Отметка «сделано» — единственное, что пишет страница, и
  живёт она в браузере: это не данные хозяйства, а состояние того, кто сейчас во
  дворе. На другом устройстве галочек не будет — так и задумано.
- **Пароль** — и вход, и ключ к файлам. В `index.html` лежит только SHA-256-хэш
  (`PASSWORD_HASH`), коммитить его безопасно; сам пароль в репозиторий не
  попадает — он в `.env`, который в `.gitignore`.

## Что на экране

| | |
|---|---|
| **Список** | день за днём, время слева, «сейчас» и «ближайшее» видно сразу |
| **Неделя** | сетка по часам: где день плотный, а где окно |
| **Месяц** | сентябрь целиком, дни хозяйства со счётом сделанного |
| **Памятка** | кто есть, правила двора, разовые дела и вопросы к маме |
| **Метки** | `#кто-есть`, `#правила`, `#двор`, `#спросить-маму` — фильтр в меню |
| **Мелочи** | тёмная тема, погода в Омске с советом, ссылка помнит вид и фильтры |

## Работа с делами

```bash
python tools/vault.py list
python tools/vault.py list --from 03.09.2026 --to 04.09.2026
python tools/vault.py add --subject "Подоить коз" --date 03.09.2026 --time 19:45 \
    --type Дойка --repeat пн,вт,ср,чт,пт,сб,вс --until 08.09.2026
python tools/vault.py edit --id 5019e955 --time 20:00
python tools/vault.py rm --id 5019e955
python tools/vault.py import --file seed.json --replace
```

Категории: `Кормёжка`, `Вода`, `Выгул`, `Дойка`, `Двор`, `Своё` — они же цвета
полосок и легенда. Ключ `--local` пишет в `my-data.local.json`: этот слой виден
только при запуске с localhost и в репозиторий не уезжает.

## Известные ограничения

- Потеря пароля — потеря дел. Расшифровать файл без него нельзя по построению.
  Исходный распорядок при этом не пропадает: он записан в заметке
  «Хозяйство мамы — расписание 3–8 сентября 2026», и залить его заново — одна
  команда `import`.
- Дела правятся только утилитой: сайт ничего не пишет, кроме своих галочек.
- Период жёстко задан датами 3–8 сентября (`PERIOD` в `index.html`). После 8-го
  дни остаются на месте как отчёт, а «сейчас» и «ближайшее» гаснут: показывать
  их было бы враньём.
