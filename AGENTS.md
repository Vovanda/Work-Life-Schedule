# Карта для агента

Где что лежит и в каком порядке читать. Файл публичный, поэтому здесь только
адреса и порядок — ни паролей, ни содержимого дел.

## Порядок при старте

1. **Правила кода** — `CLAUDE.md` в корне, обязательны к соблюдению.
2. **Модель дела** — `docs/model.md`: горизонт, повтор, отметки, метки.
3. **Устройство шифрования** — `docs/how-it-works.md`: формат файлов, вывод
   ключа, что видно постороннему.
4. **Что вообще происходит** — заметка памяти
   `main/household/Хозяйство мамы — расписание 3–8 сентября 2026`: сам распорядок,
   правила двора и то, что ещё не выяснено. Сайт показывает её содержимое;
   при расхождении правда там, а не в коде.
5. **Доступ** — заметка памяти `main/household/Сайт хозяйства — доступ и правка`:
   пароль, ветки, как править и как менять ключ.

## Что во внешней памяти

Сервер памяти — тот, что подключён у владельца. Обращаться с явным `project=main`:
значение по умолчанию неверное.

| Заметка | Что внутри |
| --- | --- |
| `main/README` | карта проектов памяти и правила записи |
| `main/household/Хозяйство мамы — расписание 3–8 сентября 2026` | распорядок, правила, расселение, вопросы к маме |
| `main/household/Сайт хозяйства — доступ и правка` | пароль, ветки, работа с утилитой |

Заметка и сайт должны сходиться. Меняешь распорядок — правь оба, в одной правке.

## Что на диске и не в git

| Путь | Что это |
| --- | --- |
| `.env` | `SCHEDULE_PASSWORD` — пароль к делам, единственное, чего нет в репозитории |
| `*.local.json` | выдуманные дела для проверки вёрстки, видны только с localhost |
| `node_modules/` | playwright для `tools/smoke.mjs`, ставится разово |

## Ветки

Работа идёт в `main`: сайт публикуется с него через GitHub Pages, и ветка,
не влитая в `main`, значит сайт, которого никто не видит. Ветка
`claude/update-66kpso` держится вровень с `main` — это след сессии, а не
отдельная линия разработки.

## Чего не делать

- Не коммитить `.env` и расшифрованные дела.
- Не переписывать заметку памяти целиком: правки точечные, через `edit_note`.
- Не менять пароль в `index.html`, не перевыпустив файлы: пароль — ещё и ключ.
