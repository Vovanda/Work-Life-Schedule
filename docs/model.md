# Модель дела

Сущность одна — **дело**. Пункт распорядка, разовая задача, правило двора и
вопрос к маме — это не разные вещи, а одно и то же на разной степени
определённости. Разделять их отдельными файлами значит трижды описывать одно.

## Горизонт

Главное поле — `horizon`: насколько точно дело привязано ко времени.

| Горизонт | Что задано | Пример |
| --- | --- | --- |
| `time` | день и час | подоить коз в 19:45 |
| `day` | день, часа нет | помыть посуду, найденную во дворе |
| `week` | период, дня нет | расчистить двор за 3–8 сентября |
| `month` | месяц | — (в этом периоде не встречается) |
| `season` | срока нет | правила двора, расселение, вопросы к маме |

Обязательные поля зависят от горизонта, и только от него:

- `time` — нужны `date` и `time`;
- `day` — нужен `date`;
- `week`, `month` — нужен `period`;
- `season` — только название.

## Повтор

Распорядок повторяется каждый день, но хранится **одной записью с правилом**:

```
repeat: {days: [0..6], until: "08.09.2026"}
skip:   ["05.09.2026"]            отменить одно повторение
move:   {"05.09.2026": "06.09.2026"}   перенести на другую дату
```

Тридцать копий одного дела означали бы тридцать правок при сдвиге на час.

## Отметки

`done` — **список дат**, а не флаг: у повтора одна запись на все шесть дней, и
флаг закрыл бы сразу весь период. Ставит утилита:

```bash
python tools/vault.py done --date 03.09.2026              # весь день
python tools/vault.py done --date 03.09.2026 --id 5019e955
python tools/vault.py undone --date 03.09.2026
```

Сайт отметки только показывает: он статический, и галочка, поставленная в
браузере, осталась бы в этом браузере.

## Категории и метки

`type` — что это за дело, он же цвет полоски: `Кормёжка`, `Вода`, `Выгул`,
`Дойка`, `Двор`, `Своё`. Список закрыт и живёт в `MY_TYPE` в `index.html` и в
`TYPES` в утилите.

`tags` — свободные метки, по ним группируется памятка и работает фильтр:
`питомник`, `вольеры`, `правила`, `кто-есть`, `двор`, `спросить-маму`.
Метка `разобрать` означает «ждёт ответа мамы» и подсвечивается отдельно.

## Поля целиком

```
id        строка, задаётся утилитой
subject   что за дело
horizon   time | day | week | month | season
date      ДД.ММ.ГГГГ — при time и day
time      ЧЧ:ММ — при time
duration  минут; без неё дело считается точкой и не даёт ложных наложений
period    "ДД.ММ.ГГГГ-ДД.ММ.ГГГГ" — при week и month
type      категория из MY_TYPE
room      где: баня, кухня, пристройка, вольер 3
note      заметка
tags      метки
repeat    правило повтора; skip и move — его исключения
done      список дат, когда сделано
parent    id дела, из которого это выросло
```

## Как это видно на сайте

- `time` — в списке на своём часе и в сетке недели;
- `day` — в списке дня, без часа, и в счёт «сделано» не входит;
- `week` — полосой над расписанием: помнить надо каждый день периода;
- `season` — только в «Памятке»: в сетке ему нечего делать.

Длительность нужна, чтобы видеть наложения. Дело без неё — точка: чай с бабулей
занимает час и режет всё, что в него попадает, а «открыть вольер» — мгновение и
не конфликтует ни с чем.
